# Доверенные сертификаты для T-Invest API

API Т-Инвестиций (`invest-public-api.tbank.ru`) использует сертификат российского
удостоверяющего центра Минцифры — **Russian Trusted Root CA**. Его нет в стандартном
списке Node.js, поэтому без этого файла сервер не может подключиться к API
(ошибка `SELF_SIGNED_CERT_IN_CHAIN`).

Положите сюда корневой сертификат с официального сайта Госуслуг:
<https://www.gosuslugi.ru/crt> → «Корневой сертификат» (`russian_trusted_root_ca_pem.crt`).

`server.js` читает все файлы `*.pem`, `*.crt`, `*.cer` из этой папки (PEM или DER)
и добавляет их к стандартным сертификатам **только для запросов к T-Invest API**.
Сертификат публичный — это не секрет, хранить его в репозитории безопасно.
