# FinPulse — веб-терминал финансовой аналитики

Одностраничное приложение: акции, облигации, дивидендный календарь, новости,
портфель/избранное и интерактивный график в стиле TradingView. Тёмная тема по
умолчанию (есть переключатель на светлую), адаптивная вёрстка (desktop / tablet / mobile).

## Деплой на Railway

Сайт работает в Docker-образе с небольшим сервером на Node.js (`server.js`, без зависимостей);
настройки деплоя — в `railway.json`.

1. [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo** → `finpulse`.
2. Сервис → **Settings → Networking → Generate Domain** — публичный адрес `….up.railway.app`.
3. Каждый push в `main` пересобирает и перезапускает сайт.

### Данные Т-Инвестиций (мультипликаторы и дивиденды)

Чтобы в скринере были P/E, P/B, ROE, долг/EBITDA, рентабельность и дивидендная доходность по всем акциям,
а в календаре — дивиденды сразу после объявления, добавьте в сервис переменную:

| Переменная | Значение |
|---|---|
| `T_INVEST_TOKEN` | токен T-Invest API с доступом **«Только чтение»** (создаётся в настройках Т-Инвестиций на сайте tbank.ru) |

Сервер раз в 6 часов загружает данные методами `GetAssetFundamentals` и `GetDividends`
и отдаёт их сайту через `/api/fundamentals` и `/api/dividends`. Токен остаётся только на сервере:
в браузер, ответы и логи он не попадает. Методы счёта и портфеля не вызываются.
Без токена сайт работает на открытых данных MOEX и справочных мультипликаторах.

Служебные адреса: `GET /healthz` (проверка Railway), `GET /api/status` (состояние загрузки данных и причина ошибки),
`GET /api/diag` (проверка связи с T-Invest API без токена: DNS, сертификат, ответ сервера).

Проверить образ локально:

```bash
docker build -t finpulse .
docker run --rm -p 8080:8080 -e T_INVEST_TOKEN=... finpulse
# http://localhost:8080
```

## Запуск локально

Сборка не нужна — достаточно открыть `index.html` в браузере.
Или поднять статический сервер:

```bash
node server.js            # или: python -m http.server 8080
# http://localhost:8080
```

Библиотеки грузятся с CDN: Tailwind CSS (Play CDN), TradingView Lightweight Charts 4.1.3,
Lucide Icons, шрифты Inter / JetBrains Mono.

## Возможности

- **Шапка**: поиск с автодополнением по тикеру, названию и ISIN (клавиши `/`, `↑`, `↓`, `Enter`, `Esc`),
  статус сессии MOEX по времени МСК, бегущая строка индексов/валют/сырья/крипто с обновлением в реальном времени.
- **График**: интервалы 1D (5 мин), 1W (1 ч), 1M, 1Y (дни), ALL (недели); свечи / линия; объёмы;
  OHLC под курсором; изменение за день и за период; последняя свеча обновляется на тиках.
  Метрики: объём и оборот, P/E, див. доходность, капитализация, 52-нед. и дневной диапазоны.
- **Рисование на графике** (как в TradingView): трендовая линия, луч, горизонтальная и вертикальная линии,
  параллельный канал, прямоугольник, коррекция Фибоначчи, линейка (изменение цены в ₽ и %, число баров), текст.
  Выделение и перетаскивание, цвет и толщина, магнит к OHLC, Ctrl+Z, Delete, Esc, горячие клавиши Alt+буква.
  Рисунки хранятся в браузере для каждой бумаги и не сбиваются при смене интервала.
- **Акции**: лидеры роста/падения, самые торгуемые, обзор рынка (ширина рынка, секторы),
  таблица с фильтром по секторам, сортировкой и 30-дневными спарклайнами. Клик по бумаге загружает её график.
- **Скринер акций**: все акции TQBR и иностранные акции FQBR с MOEX; фильтры по стране (по ISIN), отрасли
  (состав отраслевых индексов MOEX), капитализации, P/E, P/B, ROE, долгу/EBITDA, дивидендной доходности и росту за год;
  готовые наборы («Дивидендные», «Недооценённые», «Качество», «Растут за год», «Голубые фишки»), сортировка по любому столбцу.
  Мультипликаторы — из T-Invest API по всем акциям (если задан `T_INVEST_TOKEN`), иначе ориентировочные значения по МСФО из `js/fundamentals.js` для 13 основных бумаг.
- **Скринер облигаций**: все ОФЗ (постоянный купон, флоатеры, линкеры) и корпоративные выпуски TQCB; фильтры по типу,
  валюте, отрасли эмитента (по названию), стране, рейтингу, YTM, сроку, купону, дюрации, частоте выплат и наличию сделок.
- **Облигации**: ОФЗ и корпоративные, YTM, купон, периодичность, дюрация, погашение, рейтинг;
  фильтр, сортировка, кривая доходности (SVG), карточка выпуска с ближайшим купоном.
- **Дивиденды**: предстоящие / прошедшие, группировка по месяцам, «купить до» (T+1), дата отсечки,
  размер выплаты, доходность к текущей цене, статус «Рекомендовано / Одобрено».
- **Новости**: фильтр по тегам (Акции / Облигации / Макро) и влиянию на рынок; кликабельные тикеры.
- **Экономические циклы**: модель «инвестиционных часов» (спад → восстановление → перегрев → стагфляция).
  Фаза считается по рыночным сигналам (тренд IMOEX к SMA200, ширина рынка, наклон кривой ОФЗ, циклические сектора
  против защитных, нефтегаз против рынка) и по макро-оценке пользователя (динамика ВВП и инфляции по данным Росстата и ЦБ).
  Для каждой фазы — какие активы, сектора и облигации обычно выигрывают; справка по циклам экономики России.
- **Калькуляторы**: сложный процент (капитализация, пополнения с индексацией), ипотека (аннуитет и дифференцированный
  платёж), досрочное погашение (сокращение срока или платежа), финансовая цель с учётом инфляции, рефинансирование
  (выгода и срок окупаемости расходов), облигации (YTM с НДФЛ и НКД, поток выплат, подстановка выпуска с биржи),
  конвертер по курсу ЦБ РФ, инфляция по данным Росстата 2010–2024 или своей ставке. Графики, таблицы, значения
  запоминаются в браузере; прямые ссылки вида `#calc/mortgage`.
- **Портфель**: избранное (★) + количество и средняя цена → стоимость, P&L, изменение за день, структура.
  Хранится в `localStorage`.
- Deep-link на бумагу: `index.html#stocks/YDEX`.

## Источники данных

Сайт сам загружает данные прямо из браузера через открытые API без ключей (`js/sources/live.js`):

| Раздел | Источник |
|---|---|
| Акции (13 бумаг TQBR), свечи 10 мин / 1 ч / день / неделя | MOEX ISS — `iss.moex.com` |
| IMOEX, RTSI | MOEX ISS, рынок индексов |
| Юань | MOEX ISS, `CNYRUB_TOM` |
| Доллар, евро | официальный курс ЦБ РФ (`cbr-xml-daily.ru`); биржевые торги USD/EUR на MOEX остановлены в 2024 г. |
| Brent, золото, S&P 500, NASDAQ | фьючерсы MOEX (`BR`, `GOLD`, `SPYF`, `NASD`), самый ликвидный контракт |
| Bitcoin, Ethereum | CoinGecko |
| Облигации | MOEX ISS: ОФЗ-ПД (`TQOB`) и 15 самых торгуемых корпоративных (`TQCB`) |
| Дивиденды | MOEX ISS `/securities/{ticker}/dividends` |
| Новости | новости MOEX + RSS РБК (через rss2json), теги и влияние определяются автоматически |

Котировки обновляются каждые 20 с. **Бесплатные данные MOEX ISS приходят с задержкой ~15 минут**;
поток без задержки требует платной подписки MOEX (например, AlgoPack).

Справочные поля, которых нет в открытых API: сектор, EPS (для P/E), бета, кредитные рейтинги корпоративных облигаций
(известны только для нескольких эмитентов уровня AAA, у остальных «н/д»).

Если живые источники недоступны (нет сети, сайт открыт в песочнице, блокирующей внешние запросы), страница
автоматически переключается на демо-данные (`js/sources/demo.js`). В шапке всегда видно, какие данные на экране.
Принудительный демо-режим: `index.html?demo`.
