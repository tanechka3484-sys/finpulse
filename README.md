# FinPulse — веб-терминал финансовой аналитики

Одностраничное приложение: акции, облигации, дивидендный календарь, новости,
портфель/избранное и интерактивный график в стиле TradingView. Тёмная тема по
умолчанию (есть переключатель на светлую), адаптивная вёрстка (desktop / tablet / mobile).

## Запуск

Сборка не нужна — достаточно открыть `web/index.html` в браузере.
Или поднять статический сервер:

```bash
cd web
python -m http.server 8080
# http://localhost:8080
```

Библиотеки грузятся с CDN: Tailwind CSS (Play CDN), TradingView Lightweight Charts 4.1.3,
Lucide Icons, шрифты Inter / JetBrains Mono.

## Структура

```
web/
├── index.html          # разметка всех разделов
├── css/styles.css      # дизайн-токены (CSS-переменные), компоненты, анимации, скелетоны
└── js/
    ├── utils.js        # форматирование чисел/дат (ru-RU), seeded RNG, localStorage, спарклайны
    ├── mock-data.js    # моки: индексы, 13 акций, 12 облигаций, дивиденды, новости
    ├── api.js          # слой данных MarketAPI: генерация истории, «реалтайм»-тики
    ├── chart.js        # обёртка над Lightweight Charts (свечи/линия, объёмы, OHLC-легенда)
    └── app.js          # UI: роутинг вкладок, рендер, поиск, фильтры, портфель
```

## Возможности

- **Шапка**: поиск с автодополнением по тикеру, названию и ISIN (клавиши `/`, `↑`, `↓`, `Enter`, `Esc`),
  статус сессии MOEX по времени МСК, бегущая строка индексов/валют/сырья/крипто с обновлением в реальном времени.
- **График**: интервалы 1D (5 мин), 1W (1 ч), 1M, 1Y (дни), ALL (недели); свечи / линия; объёмы;
  OHLC под курсором; изменение за день и за период; последняя свеча обновляется на тиках.
  Метрики: объём и оборот, P/E, див. доходность, капитализация, 52-нед. и дневной диапазоны.
- **Акции**: лидеры роста/падения, самые торгуемые, обзор рынка (ширина рынка, секторы),
  таблица с фильтром по секторам, сортировкой и 30-дневными спарклайнами. Клик по бумаге загружает её график.
- **Облигации**: ОФЗ и корпоративные, YTM, купон, периодичность, дюрация, погашение, рейтинг;
  фильтр, сортировка, кривая доходности (SVG), карточка выпуска с ближайшим купоном.
- **Дивиденды**: предстоящие / прошедшие, группировка по месяцам, «купить до» (T+1), дата отсечки,
  размер выплаты, доходность к текущей цене, статус «Рекомендовано / Одобрено».
- **Новости**: фильтр по тегам (Акции / Облигации / Макро) и влиянию на рынок; кликабельные тикеры.
- **Портфель**: избранное (★) + количество и средняя цена → стоимость, P&L, изменение за день, структура.
  Хранится в `localStorage`.
- Deep-link на бумагу: `index.html#stocks/YDEX`.

## Подключение реального API

UI обращается к данным только через `FP.API` (`js/api.js`). Достаточно заменить тела методов
`getStocks`, `getBonds`, `getDividends`, `getNews`, `getIndices`, `getHistory`, сохранив форму объектов
(поля описаны в комментариях `js/mock-data.js`), а симуляцию тиков в `subscribe()` — на WebSocket или polling.

Примеры источников:

| Данные     | MOEX ISS                                                                 | Альтернативы                         |
|------------|--------------------------------------------------------------------------|--------------------------------------|
| Акции      | `/iss/engines/stock/markets/shares/boards/TQBR/securities.json`          | FMP `/api/v3/quote`, Alpha Vantage   |
| Свечи      | `/iss/engines/stock/markets/shares/securities/{SECID}/candles.json`      | Yahoo Finance chart API              |
| Облигации  | `/iss/engines/stock/markets/bonds/securities.json`                       | —                                    |
| Дивиденды  | `/iss/securities/{SECID}/dividends.json`                                 | FMP `/stock_dividend_calendar`       |

> Все данные в демо — сгенерированные и не являются инвестиционной рекомендацией.
